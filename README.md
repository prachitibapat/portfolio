# Prachiti Bapat — Portfolio

Personal portfolio site for Prachiti Bapat, a software engineer based in Los Angeles (M.S. Computer Science, USC).

It covers my experience at Easley Dunn Productions, Lux Vitae, and Amazon, plus selected projects in databases, reinforcement learning, and route optimization.

## Tech stack

Next.js, React, TypeScript, Tailwind CSS, Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
